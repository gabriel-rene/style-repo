# Neo-Brutalism

## summary
Neobrutalism is a visual design trend marked by high contrast, blocky layouts, bold colors, thick borders and deliberately unpolished elements. Nielsen Norman Group describes it as an evolution of brutalist web design that mixes the brutalist approach with nostalgic graphic elements from the 1990s. Common features include vivid color pairings, solid rather than soft drop shadows, geometric shapes without gradients, quirky typefaces and retro interface touches. Compared with plain brutalism, it tends to be more colorful and orderly.
